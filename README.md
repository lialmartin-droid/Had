# Nokia Had 8

Mobilní retro hra připravená pro GitHub Pages. Had začíná jako samotná hlava a po každém běžném soustu naroste o jeden dílek.

## Obsah

- Klasika s průchodem zdmi
- Survival s postupně přibývajícími překážkami
- Dvouminutová časovka
- Denní výzva se stejnou mapou pro všechny pokusy daného dne
- Komba, zlaté sousto, zpomalení a dvojnásobné body
- Pět prostředí měnících se během hry
- Volitelné barvy, rekordy, statistiky a mise
- Ovládání tlačítky, šipkami, WASD i přejetím po displeji
- Vlastní ikona pro záložku, iPhone a instalovanou aplikaci
- Offline spuštění po prvním načtení

Pro GitHub Pages nahraj všechny soubory z této složky do kořene repozitáře.
